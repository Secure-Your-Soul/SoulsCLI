## 📋 Requirements

- 🦀 **Rustc 1.98.1**
- **Git 2.55.0**

## 📦 Installation

```sh
cargo install souls-cli
```

## 🚀 Usage
```sh
s --help          # show all commands
s new my-project  # create a new project
s menu            # open interactive menu
```
